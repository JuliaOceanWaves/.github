# JuliaOceanWaves

The JuliaOceanWaves organization is a collection of tools for modeling floating structures, with applications to naval architecture and wave energy converters. 
These tools are currently developed through a collaboration between [Sandia National Laboratories](https://energy.sandia.gov/programs/renewable-energy/water-power/) and the [University of Michigan](https://me.engin.umich.edu/). 
The focus is on performant and differentiable tools that can be used in advanced gradient-based optimization approaches such as MDAO and pseudo-spectral methods for control co-design.

Packages include:
* _**WaveSpectra.jl**_: Represent wave spectral density and calculate wave statistics.
* _**BuoyData.jl**_: Intake wave spectrum from buoy data, such as NDBC buoys.
* _**MarineHydro.jl**_: Solve potential flow diffraction and radiation problems for floating structures using the boundary element method.
